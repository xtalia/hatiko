# Ozon Middle Click

Независимый Tampermonkey userscript, восстанавливающий поведение средней кнопки мыши на Ozon.

- Файл: `OzonMiddleClick.user.js`
- Сайт: `*://*.ozon.ru/*`
- Permissions: `@grant none`

Устанавливается и развивается отдельно от главного `js/memchat.user.js`. Перед установкой следует просмотреть код и проверить работу на тестовой странице Ozon.

Текущая версия указана в metadata block userscript-а.
