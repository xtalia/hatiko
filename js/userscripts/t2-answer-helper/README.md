# T2 Answer Helper

Независимый Tampermonkey userscript для извлечения ответов из теста T2 и подсветки правильных вариантов.

Файл установки: `T2-Answer-Helper.user.js`.

Не связан с `memchat.user.js`.

## Установка

Откройте `T2-Answer-Helper.user.js` через Tampermonkey и установите скрипт.

## Область работы

Скрипт ограничен страницами `https://*.t2.ru/*`, как указано в metadata block.

## Permissions

Используются `GM_addStyle` и `GM_registerMenuCommand`.

## Проверка

После установки откройте тест T2 и проверьте, что меню Tampermonkey появляется, а варианты ответа подсвечиваются.

## Поддержка

Скрипт хранится отдельно от главного `memchat.user.js`; изменения главного userscript-а не должны менять его поведение.

## Версия

Текущая версия указана в metadata block самого userscript-а.

## Безопасность

Перед установкой просмотрите код и permissions. Скрипт работает в браузере и не требует собственного сервера.

## Лицензия

Отдельная лицензия для этого файла в репозитории не указана.

## Структура

В папке находятся только userscript и его README.

## Совместимость

Ориентирован на Tampermonkey и современные Chromium-браузеры.

## Данные

Отдельные JSON-файлы не требуются.

## Релизы

Версия релиза совпадает с версией в metadata block.

## Архив

Старые экспериментальные версии находятся в `js/archive/unused-userscripts/`, если они когда-либо были добавлены.

## Завершение

Скрипт не является частью сборки `memchat`.

## Источник

Основной репозиторий называется `hatiko`.

## Ручной smoke-test

Установить скрипт, открыть T2, открыть меню Tampermonkey и проверить подсветку.

## Ограничения

## Локальность

Скрипт не требует runtime-зависимостей из Node.js или Python.
