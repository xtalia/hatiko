# Polymarket helper

Независимый userscript для Polymarket: `polyc.user.js`.

Он не является частью главного serverless userscript-а `js/memchat.user.js` и размещён отдельно, чтобы не смешивать разные предметные области.

## Статус

Скрипт сохранён в рабочем разделе независимых userscript-ов. Старое Python-приложение Polymarket находится в `archive/polymarket-app/` и не является runtime-зависимостью этого userscript-а.

## Установка

Открыть `polyc.user.js` через Tampermonkey и установить его отдельно.

## Область работы

`https://polymarket.com/*`.

## Permissions

`@grant none`.

## Данные

Настройки сохраняются локально в `localStorage` браузера. Секреты и торговые ключи в репозитории храниться не должны.

## Важно

Перед использованием и установкой самостоятельно проверить актуальные правила сайта, риски автоматизации и содержимое userscript-а.

## Дальнейшее решение

Если Polymarket-инструменты будут развиваться отдельно, папку можно вынести в самостоятельный репозиторий без изменения структуры `memchat`.

## Тестирование

Установить скрипт в отдельный профиль браузера и проверить интерфейс на тестовом сценарии без реальных операций.

## Источник

Основной репозиторий называется `hatiko`.

## Совместимость

Tampermonkey и современный Chromium-браузер.

## Лицензия

Отдельная лицензия не указана.

## Архив

Старое Python-приложение не подключается автоматически.

## Без сервера

Userscript работает в браузере и не требует backend для загрузки кода.

## Версия

Версия указана в metadata block.

## Зависимости

Runtime-зависимости отсутствуют.

## Поддержка

Поддерживается отдельно от `memchat.user.js`.

## Конец

Папка содержит независимый Polymarket-инструмент.
